# Employee Payroll Management System

A PHP/MySQL-based payroll management web application that handles employee records, branches, departments, designations, shifts, and payroll processing through an admin dashboard.

Originally developed by [MD MAFUJUL HASAN](https://github.com/MD-MAFUJUL-HASAN/Online-Payroll-Management-System).

## What I did
Deployed and configured this project locally using XAMPP (Apache, MySQL, phpMyAdmin):
- Resolved a MySQL port conflict (default port 3306 was occupied) and reconfigured phpMyAdmin and the application's database connection accordingly
- Recovered a missing database schema (`payrollmanage.sql`) using Git version history
- Set up and tested the full application end-to-end, from server configuration to login

## Tech Stack
PHP, MySQL, HTML, CSS, JavaScript, XAMPP (Apache, phpMyAdmin)
